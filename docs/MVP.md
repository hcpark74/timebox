# Timebox Flow MVP

## 목표

Timebox Flow의 MVP는 많은 할 일 목록 중 오늘 실행할 핵심 3~4개를 고르고, 이를 정해진 시간 블록에 배치한 뒤, 하루를 끝까지 실행할 수 있게 돕는 상태를 의미합니다.

핵심은 복잡한 계획 기능이 아니라 다음 세 가지입니다.

- 할 일 목록에서 오늘 할 일을 빠르게 고를 수 있다.
- 선택한 일을 하루 블록에 배치할 수 있다.
- 완료/미완료를 기준으로 하루를 마무리할 수 있다.

## MVP 포함 범위

### 1. 기본 화면

- `오늘 일정`
- `캘린더`
- `할 일 정리`
- `시간 배치`
- `내 정보`

참고:

- `통계`는 확장 기능으로 보고 MVP 필수 범위에서는 제외합니다.

### 2. 할 일 목록 관리

- 새 태스크 추가
- 태스크 삭제
- 할 일 목록에 후보 작업 보관

### 3. 오늘의 핵심 선정

- `할 일 목록`과 `오늘의 핵심` 간 드래그 앤 드롭 이동
- 오늘의 핵심 작업 3~4개 선정
- 우선순위 목록 재조정

### 4. 시간 블록 배정

- 선택한 날짜 기준으로 작업 배치
- `오늘의 핵심`의 작업을 시간 슬롯에 드롭해 배정
- 같은 슬롯에 새 작업을 놓으면 기존 배정 해제
- 현재 선택 날짜의 배치 초기화

### 5. 실행 및 확인

- 오늘 일정에서 시간순으로 배치된 작업 확인
- 완료 상태 토글
- 날짜별 일정 목록 확인
- 빈 상태 메시지 표시

### 6. 저장 방식

- 기본 저장: `localStorage`
- 앱 재방문 시 데이터 유지
- 서비스 워커 기반 기본 오프라인 셸

## MVP에서 기대하는 사용 방식

MVP는 다음 흐름이 자연스럽게 가능해야 합니다.

1. 사용자가 `할 일 목록`에 할 일을 모은다.
2. 그중 오늘의 핵심 3~4개를 `오늘의 핵심`으로 고른다.
3. 이를 하루 블록에 배치한다.
4. `오늘 일정`에서 실행한다.
5. 완료/미완료를 체크하고 남은 일은 다음 날 다시 조정한다.

## MVP 제외 범위

아래 항목은 MVP에 포함하지 않습니다.

- `통계` 탭
- 세밀한 타이머 기능
- 푸시 알림
- AI 자동 배치
- 외부 캘린더 연동
- 반복 일정
- 협업 기능
- 상세 리포트 / 고급 분석
- 로그인 / 계정 시스템

## 선택 기능

아래는 있으면 좋지만, MVP 출시 필수는 아닙니다.

- Cloudflare KV 기반 동기화 ID 동기화
- 카테고리/우선순위 입력 UI 고도화
- 버퍼 블록 전용 UI 강화
- PWA 아이콘 및 설치 경험 보강

## 완료 기준

다음 조건을 만족하면 MVP로 간주합니다.

- 사용자가 할 일 목록에 할 일을 추가하고 삭제할 수 있다.
- 사용자가 `오늘의 핵심`에 오늘의 핵심 3~4개를 고를 수 있다.
- 사용자가 작업을 시간 슬롯에 배치할 수 있다.
- 사용자가 날짜를 바꿔 일정과 타임라인을 확인할 수 있다.
- 사용자가 완료 상태를 변경할 수 있다.
- 새로고침 후에도 로컬 데이터가 유지된다.
- 모바일 화면에서 주요 흐름이 깨지지 않는다.
