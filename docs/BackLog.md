# Timebox Flow Backlog

## 목적

이 문서는 Timebox Flow를 `할 일 목록 -> 오늘의 핵심 -> 시간 블록 -> 실행` 흐름의 데일리 실행 플래너로 발전시키기 위한 우선순위 기반 작업 목록입니다.

현재 우선순위는 통계 중심이 아니라, 사용자가 매일 같은 방식으로 계획하고 실행할 수 있도록 현재 UI를 플래너 목적에 더 가깝게 다듬는 데 있습니다.

## P1 - 제품 핵심 흐름 강화

### 1. 오늘의 핵심 3~4개 제한 UX

- `오늘의 핵심`에 너무 많은 작업이 들어가지 않도록 제한
- 3~4개를 넘기려 할 때 안내 문구 표시
- 오늘 핵심 작업을 선택하는 경험을 명확히 강화

이유:

- 이 제품의 핵심 사용 방식이 "오늘의 핵심 3~4개 선택"이기 때문
- 현재 UI는 가능하지만 제품 규칙으로는 아직 약함

### 2. 고정 시간 블록 중심 스케줄링

- 스케줄링 화면을 다음 블록 중심으로 해석되도록 개선
  - `09:00 - 11:30`
  - `13:00 - 15:00`
  - `15:00 - 17:00`
  - `17:00 - 18:00` 버퍼
- 자유 슬롯 배치보다 주요 블록 사용을 먼저 유도
- 버퍼 블록을 별도 시각 처리하는 방안 검토

이유:

- 실제 사용 목적이 고정 블록 운영에 있음
- 현재 타임라인은 자유 시간표 성격이 강함

### 3. 할 일 목록 입력 UX 개선

- 새 태스크 입력 영역을 더 빠르게 사용 가능하게 정리
- 기본적으로 후보 할 일을 쌓는 공간이라는 의미를 강화
- 태스크 생성 시 기본 상태와 문구를 플래너 흐름에 맞게 정리

이유:

- 사용 시작점이 항상 `할 일 목록`이기 때문
- 첫 입력 경험이 전체 앱 인상을 결정함

### 4. 하루 마무리 흐름 정리

- 완료 / 미완료 구분을 더 명확하게 표시
- 미완료 작업을 다음 날 다시 계획할 수 있는 흐름 검토
- 버퍼 블록에서 처리된 작업을 자연스럽게 확인 가능하게 개선

이유:

- 이 앱은 기록보다 실행과 하루 마감 흐름이 중요함

## P2 - MVP 다음 단계에서 유효

### 5. 통계 탭 구현

- `검색 예정` 자리를 `통계`로 교체
- 오늘 완료 수, 스케줄 수, 완료율 표시
- 향후 버퍼 사용량과 계획 대비 완료율로 확장 가능하게 설계

이유:

- 현재 제품 핵심은 아니지만, 실행 결과를 돌아보는 데 유용함

### 6. 카테고리/우선순위 입력 UX 개선

- 새 태스크 추가 시 카테고리 선택
- 필요 시 우선순위 또는 성격 태그 선택
- `집중 업무`, `행정 업무`, `회의` 같은 분류 확장 검토

### 7. Cloudflare Sync 안정성 개선

- `global` 단일 키 저장 전략 재검토
- 마지막 수정 시각 추가
- 충돌 처리 규칙 정의
- 동기화 실패 시 사용자 안내 강화

### 8. 일일 리뷰 기능

- 하루 끝에 짧은 메모 작성
- 계획 대비 수행 여부 간단 기록
- 다음 날로 넘길 작업 정리 흐름 추가

## P3 - 확장 기능

### 9. 반복 일정

- 매일 / 매주 반복 블록 지원
- 반복 일정 예외 처리 규칙 정의

### 10. 알림 기능

- 블록 시작 전 알림
- 버퍼 블록 진입 알림
- PWA 설치 환경에서의 알림 UX 검토

### 11. 외부 캘린더 연동

- Google Calendar / Outlook 연동 검토
- 외부 일정과 개인 타임블록 충돌 확인

### 12. 고급 분석

- 계획 대비 완료율 추세
- 버퍼 블록 사용 빈도
- 카테고리별 시간 사용 분석
- 주간 회고 리포트

## 기술 부채 / 정리 항목

### 13. 코드 구조 분리

- `js/app.js`가 상태, 렌더링, 저장, 네비게이션을 모두 담당
- 기능별 파일 분리 검토

### 14. 스타일 구조 정리

- 인라인 스타일 축소
- 반복되는 카드/버튼 스타일 공통화
- 고정 블록 UI를 위한 스타일 체계 정리

### 15. 문구/언어 일관성

- 화면 문구와 문서 표현 기준 통일
- 버튼/탭/빈 상태 메시지 규칙 정리
- `할 일 목록`, `오늘의 핵심`, `오늘 일정` 용어 해석 일관화

## 보류 항목

### 16. 로그인 / 계정 시스템

- 현재 제품 단계에서는 우선순위 낮음
- 동기화 ID 방식으로도 당분간 운영 가능

### 17. 협업 기능

- 개인 실행 플래너 성격상 후순위

3. 할 일 목록 입력 UX 개선
4. 하루 마무리 흐름 정리
