# Timebox Flow 사용자 매뉴얼

Timebox Flow는 하루 할 일을 정리하고, 시간대별로 배정해 `오늘 일정`으로 확인할 수 있는 간단한 스케줄 관리 앱입니다.

## 처음 시작하기

처음 접속했다면 아래 순서로 사용하면 가장 자연스럽습니다.

1. `오늘 일정` 화면에서 오늘 일정이 있는지 먼저 확인합니다.
2. 일정이 없다면 `+` 버튼이나 `할 일 정리` 화면으로 이동합니다.
3. 입력창에 할 일 제목을 입력하고 `할 일 추가` 버튼을 눌러 태스크를 추가합니다.
4. 필요하면 태스크를 `오늘의 핵심`으로 옮겨 우선순위를 정리합니다.
5. `오늘의 핵심`에서는 위아래 버튼이나 드래그로 순서를 조정합니다.
6. `할 일 목록`은 접어두었다가 필요할 때 펼쳐서 확인합니다.
7. `시간 배치하기` 버튼을 눌러 스케줄링 화면으로 이동합니다.
8. 상단 주간 이동 버튼이나 날짜 바에서 계획할 날짜를 고릅니다.
9. 각 고정 블록 카드에서 `오늘의 핵심`을 고르고 `배치` 버튼으로 일정에 배정합니다.
10. `오늘 일정 보기`로 돌아와 시간순으로 정리된 일정을 확인합니다.
11. 일을 마치면 `오늘 일정`에서 체크박스를 눌러 완료 처리합니다.
12. 필요하면 `캘린더`에서 다른 날짜 일정도 확인합니다.
13. 여러 기기에서 쓰려면 `내 정보`에서 동기화 ID를 확인하거나 복사합니다.

## 화면 구성

앱에는 현재 다음 화면이 구현되어 있습니다.

### 오늘 일정

- 선택한 날짜의 스케줄을 시간대별로 확인합니다.
- 각 태스크의 체크박스를 눌러 `진행 전` / `완료` 상태를 바꿀 수 있습니다.
- 상단 달력 아이콘을 누르면 `캘린더` 화면으로 이동합니다.

### 캘린더

- 주간 날짜 목록이 표시됩니다.
- 날짜 버튼을 누르거나 키보드로 선택하면 해당 날짜 기준으로 일정 목록이 바뀝니다.
- 해당 날짜에 스케줄된 태스크가 없으면 빈 상태 메시지가 표시됩니다.

### 할 일 정리

- 태스크를 `오늘의 핵심`과 `할 일 목록`으로 나누어 볼 수 있습니다.
- 입력창에 제목을 입력하고 `할 일 추가` 버튼을 누르면 새 태스크가 추가됩니다.
- 휴지통 아이콘으로 태스크를 삭제할 수 있습니다.
- 드래그 앤 드롭으로 `오늘의 핵심`과 `할 일 목록` 사이를 이동할 수 있습니다.
- `오늘의 핵심`은 위아래 버튼이나 드래그로 수동 재정렬할 수 있습니다.
- `할 일 목록`은 토글 버튼으로 펼치거나 접을 수 있습니다.
- `할 일 목록`의 각 태스크는 별표 버튼으로 `오늘의 핵심`으로 바로 보낼 수 있습니다.

### 시간 배치

- 고정 블록 카드 안에서 `오늘의 핵심`을 선택하고 바로 배정할 수 있습니다.
- 상단 이전 주/다음 주 버튼과 날짜 바로 계획할 날짜를 바꿀 수 있습니다.
- 각 블록은 현재 배정 상태, 핵심 할 일 선택, `배정`/`해제` 버튼을 함께 보여줍니다.
- 이미 다른 블록에 배정된 핵심 할 일은 선택 목록에서 비활성화됩니다.
- 블록은 `핵심 블록 1`, `핵심 블록 2`, `핵심 블록 3`, `버퍼 블록`으로 고정되어 있습니다.
- `다시 배치`를 누르면 현재 선택된 날짜의 배정이 초기화됩니다.
- `오늘 일정 보기`를 누르면 `오늘 일정` 화면으로 이동해 결과를 볼 수 있습니다.

### 내 정보

- 사용자 인사말과 동기화 ID를 확인할 수 있습니다.
- 동기화 ID 복사 버튼으로 값을 복사할 수 있습니다.
- 수정 버튼으로 동기화 ID를 변경할 수 있습니다.
- 카테고리별 태스크 개수를 확인할 수 있습니다.

## 주요 사용 방법

### 새 태스크 추가

1. `할 일 정리` 화면으로 이동합니다.
2. 입력창에 할 일 제목을 입력합니다.
3. `할 일 추가` 버튼을 누릅니다.

새 태스크는 기본적으로 `할 일 목록`에 추가됩니다.

### 우선순위 변경

1. `할 일 정리` 화면에서 태스크를 길게 드래그합니다.
2. `오늘의 핵심` 또는 `할 일 목록` 영역으로 옮깁니다.
3. 또는 버튼으로 이동할 수도 있습니다.
   - `할 일 목록`의 별표 버튼: `오늘의 핵심`으로 이동
   - `오늘의 핵심`의 화살표 버튼: `할 일 목록`으로 이동
4. `오늘의 핵심` 안에서는 위아래 버튼으로 순서를 바꿀 수 있습니다.

`오늘의 핵심`에 들어가면 오늘 집중할 일로 처리됩니다.

### 시간 배정

1. `할 일 정리` 화면에서 `시간 배치하기` 버튼을 누릅니다.
2. 상단 이전 주/다음 주 버튼이나 날짜 바에서 계획할 날짜를 선택합니다.
3. 각 고정 블록 카드에서 `오늘의 핵심`을 선택합니다.
4. `배정` 버튼을 누릅니다.
5. 다른 블록에 이미 배정된 핵심은 선택할 수 없습니다.
6. 필요하면 `해제` 버튼으로 해당 블록을 비웁니다.
7. `오늘 일정 보기` 버튼을 눌러 오늘 일정에서 확인합니다.

같은 블록에 다른 핵심 할 일을 다시 배정하면 기존 배정은 해제됩니다.

### 완료 처리

1. `오늘 일정` 화면에서 태스크 블록을 찾습니다.
2. 체크박스를 눌러 완료 상태를 바꿉니다.

완료 상태는 저장되며 다시 열어도 유지됩니다.

### 동기화 ID 사용

1. `내 정보` 화면으로 이동합니다.
2. 표시된 동기화 ID를 복사하거나 편집합니다.
3. 같은 동기화 ID를 사용하는 환경에서는 Cloudflare KV가 설정된 경우 같은 데이터를 불러올 수 있습니다.

## 데이터 저장

- 기본 데이터는 브라우저 `localStorage`에 저장됩니다.
- 네트워크 환경과 Cloudflare 설정이 준비되어 있으면 동기화 ID 기반 동기화를 사용할 수 있습니다.
- 브라우저 저장소를 삭제하면 로컬 데이터도 함께 삭제됩니다.

## 오프라인 사용

- 서비스 워커가 기본 앱 파일을 캐시합니다.
- 한 번 로드한 뒤에는 오프라인에서도 기본 UI를 다시 열 수 있습니다.
- 다만 API 동기화는 네트워크가 필요합니다.

## 참고 사항

- 하단 탭에서 `할 일 정리` 화면으로 바로 이동할 수 있습니다.
- 통계 API 파일은 존재하지만, 별도의 통계 화면은 아직 구현되지 않았습니다.
