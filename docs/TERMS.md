# Timebox Flow 표준 용어집

## 목적

이 문서는 Timebox Flow에서 사용하는 화면 용어, 버튼 문구, 설명 표현을 일관되게 유지하기 위한 표준 용어집입니다.

문서와 UI에서 같은 개념은 가능한 한 같은 표현을 사용합니다.

## 핵심 화면 용어

- `Timebox Flow` -> `Timebox Flow`
- `Backlog` -> `할 일 목록`
- `Today's Priorities` -> `오늘의 핵심`
- `Schedule Task` -> `할 일 정리`
- `Schedule Your Task` -> `시간 배치`
- `Timeline` -> `오늘 일정`
- `Calendar` -> `캘린더`
- `Profile` -> `내 정보`
- `Stats` -> `통계`
- `Sync ID` -> `동기화 ID`

## 버튼 / 액션 용어

- `Add Task` -> `할 일 추가`
- `Open Scheduler` -> `시간 배치하기`
- `View Timeline` -> `오늘 일정 보기`
- `Re-Arrange` -> `다시 배치`
- `Done` -> `완료`
- `Pending` -> `진행 전`
- `Delete` -> `삭제`

## 설명 문구 기준

- `Backlog에 할 일을 모은다` -> `할 일 목록에 할 일을 모은다`
- `Today's Priorities에서 오늘 할 일을 고른다` -> `오늘의 핵심에서 오늘 집중할 일을 고른다`
- `Timeline에서 실행한다` -> `오늘 일정에서 실행 상태를 확인한다`
- `Schedule Your Task에서 배치한다` -> `시간 배치 화면에서 시간 블록에 배치한다`

## 권장 핵심 흐름 표기

- `할 일 목록 -> 오늘의 핵심 -> 시간 배치 -> 오늘 일정 -> 마무리`

## 번역 원칙

- 낯선 생산성 용어보다 바로 이해되는 표현을 우선한다.
- 직역보다 실제 사용 행동이 드러나는 표현을 우선한다.
- 같은 개념은 문서와 UI에서 같은 표현을 사용한다.
- `우선순위`보다 `오늘의 핵심`처럼 목적이 드러나는 표현을 선호한다.
- 영어를 유지해야 할 필요가 없다면 자연스러운 한글 표현을 우선한다.

## 참고 메모

- `Backlog`는 단순히 쌓아두는 목록이 아니라, 오늘 할 일을 고르기 전의 후보 작업 모음이다.
- `오늘의 핵심`은 많이 담는 영역이 아니라, 하루 실행의 중심이 되는 3~4개 작업을 뜻한다.
- `오늘 일정`은 단순 시간표가 아니라, 오늘 실제로 실행할 블록을 확인하는 화면이다.
